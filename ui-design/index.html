ChatQuery

UI 设计系统

面向开发者的本地数据库终端（MySQL / Redis）+ LLM 对话 + MCP 工具。本系统定义配色、字体、间距、组件与亮/暗双主题规范，作为 Tauri 桌面 GUI（React）的统一视觉基线。

设计原则

四条贯穿所有界面的核心准则。

一致优先

全局共享设计令牌，组件同源，杜绝视觉碎片化。

信息密度

开发者工具需高信息量，用紧凑间距承载更多数据。

暗色友好

默认双主题，长时间查阅结果不刺眼、不疲劳。

可达性

WCAG AA 对比度、44px 触控、键盘可达、读屏友好。

色彩系统

主色为沉稳蓝紫，语义色用于状态反馈。所有文字/背景组合满足 4.5:1 对比度。

品牌主色 Brand

语义色 Semantic

中性灰 Neutral

字体排印

UI 用 Inter / 系统字体；代码与 SQL 用等宽字体 JetBrains Mono。基准 16px，正文行高 1.6。

间距与栅格

以 4px 为基准单位（8 点节奏），保证纵向节律一致。

组件画廊

核心组件与交互态示例。完整结构见 workspace.html 与 settings.html。
