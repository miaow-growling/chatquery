# ChatQuery · UI 设计系统

> 面向开发者的本地数据库终端（MySQL / Redis）+ LLM 对话 + MCP 工具。
> 目标平台：**Tauri 桌面 GUI（React）**；交付：**可交互高保真原型 + 设计令牌**。支持 **亮 / 暗 / 跟随系统** 三态主题，遵循 **WCAG AA**。

## 2. 导航层级（已按用户要求修正）

`workspace.html` 的左侧树严格遵循以下模型，并与现有 Rust/React 代码对齐。**数据库类型（MySQL / Redis）作为树的最顶层**，Redis 分支仅在存在 Redis 链接时出现：

```
类型 (Engine: MySQL / Redis)      ← 顶层分组；无该类型链接则不显示对应分支（如没有 Redis 链接则不显示 Redis）
└── 环境 (Environment)
    └── 分组 (Group)
        └── 链接 (Connection)     ← 代码中原称「连接」，此处按用户术语用「链接」
            └── 数据库 (Database)
                ├── 表 (Tables)   ← 双击浏览数据 / 右键生成 SELECT / 表结构
                ├── 视图 (Views)
                └── 方法 (Methods) ← 存储过程/函数，新增项；双击查看定义
                    └── 表/视图/方法
                        └── 列 (Column)
Redis 链接：类型 › 环境 › 分组 › 链接 › redisdb(0..N) › 键(key)
```

> 类型分支按 `countConns(type) > 0` 动态生成：新增第一个 Redis 链接时，Redis 分支自动出现；删除最后一个时自动消失。

**术语说明（重要）**：现有代码 `frontend/src/types.ts` 与 `Tree.tsx` 将连接节点称为「连接 (connection)」，而用户要求用「链接」。原型按用户术语呈现；若要对齐代码，需将 `ConnSummary` 等文案改为「链接」。「方法」文件夹为本次新增（代码当前仅有表/视图），对应 MySQL 存储过程。

## 3. 已串联的功能（原型可真实交互）

- **左侧树**：展开/折叠（懒加载模拟）、选中、右键上下文菜单、计数徽标；`＋` 新建链接/分组/环境。
- **查询编辑器**：多 tab（新建/关闭/切换）、行号、运行(Ctrl/Cmd+Enter)、执行计划、格式化、存为片段、历史。
- **结果面板**：数据/表结构/表关系/方法 四子页；结果表格支持**双击单元格内联编辑**、行删除、新增行、保存/撤销修改、行/列多选与右键复制为 JSON/INSERT/UPDATE、导出 CSV；分页器。
- **Chat (LLM)**：可收起、流式回复模拟、发送；状态显示 LLM 是否配置。
- **状态栏**：执行耗时、返回行数、截断提示、当前链接/库。
- **设置**：LLM 厂商预设网格、API 配置、AI 内联补全开关；外观三态切换；链接管理增删改；MCP 服务开关。
- **命令面板**：⌘K / Ctrl+K 搜索连接/表/视图并跳转。
- **主题**：亮/暗/跟随系统，顶栏与侧栏双按钮同步，自动持久化。

## 4. 文件结构

```
ui-design/
├── index.html          # 设计系统总览：令牌 / 字体 / 间距 / 组件画廊（含主题切换）
├── workspace.html       # 主工作区【可交互】：树 + 编辑器 + 结果 + Chat + 状态栏
├── settings.html        # 设置页【可交互】：外观 / LLM / 链接管理 / MCP
├── assets/
│   ├── tokens.css       # 设计令牌（颜色 / 字体 / 间距 / 圆角 / 阴影 / 亮暗主题）
│   ├── components.css   # 组件库样式（含树/编辑器/结果表/Chat/菜单/弹窗）
│   └── theme.js         # 共享主题切换 + toast 工具（所有页面引用）
└── overview.md          # 本文档
```

打开方式：浏览器直接打开三个 HTML；右上角图标切主题，⌘K 唤出命令面板。

## 5. 色彩系统

- **主色 Brand**：蓝紫梯度 `--brand-50 … --brand-900`，主操作用 `--brand-500`（亮 `#4f7cff` / 暗 `#6b8aff`，暗色提亮保证对比）。
- **语义色**：成功 `#16a34a` / 警告 `#d97706` / 危险 `#dc2626` / 信息 `#0ea5e9`；暗色分别调整明度以维持 AA。
- 所有文本/背景对比满足 **WCAG AA 4.5:1**。

## 6. 排版 / 间距 / 圆角

- **字体**：UI `Inter / PingFang SC`，代码 `JetBrains Mono`。
- **字阶**：11 / 12 / 13 / 16 / 17 / 20 / 24 / 30 / 36px。
- **间距**：4px 基准（4/8/12/16/24/32/48/64px）。
- **圆角**：4 / 6 / 8 / 12 / 16 / 9999px。

## 7. 可达性

- 焦点环 `--focus-ring`；键盘可达（⌘K、Ctrl+Enter、Tab 切换）。
- 触控目标 ≥ 44px；尊重 `prefers-reduced-motion`。
- 语义化标签、ARIA 角色、读屏友好文本。
