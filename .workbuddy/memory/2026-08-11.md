- **左侧树 Redis 独立顶层分类修复**: `Tree.tsx` 的 `buildRoots` 改为按连接实际 `db_type` 拆分环境/组，不再仅按环境声明的 db_type。效果: Redis 连接独立显示在 Redis 顶层分类下；同一环境含多种类型连接时会分别出现在 MySQL/Redis 下；空环境仍按声明类型显示。
