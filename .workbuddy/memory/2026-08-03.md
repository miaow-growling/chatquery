## Chat 滚动 + 输入框优化 (bbd3ac5)
- 消息列表无滚动条：`.chat` flex 容器缺 `min-height:0` → 子元素 `.chat-log` 的 `flex:1; overflow-y:auto` 不生效（flex 默认 min-height:auto 撑开父容器）。补 `min-height:0` + `overflow:hidden` 后正常滚动。
- 输入框加高 40→56px，max-height 160px；滚动条默认隐藏、hover/focus 才现；发送按钮 38→40px。
- `.chat-log` 加 6px 宽 webkit 细滚动条（macOS overlay 风格）。
- **CSS 知识点**：flex column 布局中，子元素要能滚动必须父容器有 `min-height:0`（或 `height` 约束），否则 `min-height:auto` 让内容撑开容器，overflow 不触发。
