- 知识库「新建知识库」按钮无反应 bug 修复（前端 App.tsx）：
  - 根因：占位判定 `!kbEditing && kbName==="" && kbContent===""` 在「初始空列表」与「点了新建后」两种状态都为真——`startNewKb` 把状态重置成与初始完全相同的值，画面不变，看起来像 no-op。重启无用（非构建缓存问题，是状态逻辑缺陷）。
  - 修法：新增 `kbIsNew` 状态标志区分「列表空态」与「正在新建草稿」；编辑器展示条件改为 `!kbIsNew && !kbEditing`。`startNewKb` 置 kbIsNew=true 显示空编辑器；`editKb`/`saveKbDoc`(新)/`deleteKb` 复位为 false。

  - 用户无需重启桌面/Rust：vite HMR 已热更（或窗口内 Cmd+R）。仅生产构建需重新 build。
