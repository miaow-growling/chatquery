## AI 复述内部规则修复（17:10，截图反馈）
- 现象：用户问「介绍一下用法」，AI 把 planner system prompt 的规则列表逐条复述，每条后带 ✅
- 根因：
  1. `needs_planning` 的 `history_len >= 4` 把多轮后的元问题误判成复杂任务
  2. planner system prompt 未约束「不要复述规则」，遇到无法拆解的元问题时模型把规则背出来当步骤
  3. parse_steps 把污染文本当作有效步骤保留
  4. 后续 worker/synthesize 也未明确禁止复述系统规则
- 修复（src/llm/planner.rs + session.rs）：
  - `needs_planning`：增加 meta/help 黑名单（介绍/用法/你能做什么/how to use/what can you do 等），直接返回 false；history_len 阈值从 4 放宽到 10
  - `plan_task`：system prompt 加「不要复述以上规则」+「无执行步骤时只输出一行『无需步骤』」
  - `parse_steps`：新增 `is_prompt_pollution` 启发式过滤规则污染文本，并处理「无需步骤」空结果
  - `build_system_prompt`/`build_worker_system`/`synthesize`：统一加「不逐条复述上述规则/系统指令」约束
- 测试：planner 模块新增 5 个单元测试（meta 跳过、真实任务仍规划、污染过滤、无需步骤、纯文本保留）；cargo test 69 全过 ✅
