# 2026-08-06 工作日志

## 知识库"Command add_kb_doc not found"修复
- 现象：前端点"创建"报 `Command add_kb_doc not found`。
- 排查：前端 api.ts 调用 add_kb_doc/update_kb_doc/list_kb_docs/delete_kb_doc/set_kb_bindings；
  后端 store/mod.rs 存储层 + commands.rs 命令函数 + main.rs invoke_handler 注册**三者都已完整存在且编译通过**。
- 根因：运行时二进制是旧的——知识库命令函数（43bd829）比 invoke_handler 注册（d2f2e3d）早，
  旧二进制只编进了函数没编进注册 → Tauri 找不到命令。属"后端新增命令后没重启应用"的典型坑。
- 修复：`cargo run --manifest-path src-tauri/Cargo.toml --no-default-features` 重启，拉起最新二进制。
- **教训**：Tauri 桌面端"Command X not found"几乎都是旧二进制导致，不是注册缺失；
  后端改了命令/新增命令后必须重启 cargo（前端改动才走 vite HMR）。排查顺序：先确认 main.rs invoke_handler 是否注册 → 再确认运行中的二进制是不是新的。
