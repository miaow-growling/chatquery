# ChatQuery · UI/UX 全功能设计方案与视觉规范 (V2.0 全量版)

> **核心原则**：**现有功能零删减、全面升维、100% 承接现有业务能力**。  
> **产品定位**：面向专业开发者、DBA 与数据分析师的新一代本地数据库管理客户端（MySQL / Redis），极低资源占用、原生流式 LLM 对话交互与 MCP 工具链隔离。  
> **设计基调**：**Modern Pro Dark（现代极客暗色） + Data-Dense（高信息密度工作台） + AI-Native（原生智能副驾驶）**。

## 2. 视觉层级与设计系统（Design System）

### 2.1 表面阶梯 (Surface Elevation)
利用现代深空蓝黑色系替代粗糙线条，形成自然而分明的层次感：
- **`--bg-base` (`#090B10`)**：应用底层画布，沉浸低刺激；
- **`--bg-surface` (`#11141E`)**：常规工作面板（侧边栏、编辑器工作区、结果栏外框）；
- **`--bg-elevated` (`#181D2C`)**：悬浮交互层（卡片、AI 气泡、对话输入框、右键菜单、命令面板）；
- **`--bg-input` (`#0E121B`)**：代码输入区与深凹槽（Line Numbers、Terminal）。

### 2.2 边框与微光 (Border & Subtle Glow)
- 边框统一采用 `1px solid #232A3D`，悬浮态采用 `#333C57`；
- AI 组件与运行按钮使用蓝紫品牌渐变 `linear-gradient(135deg, #6366F1, #8B5CF6, #A855F7)` 配合轻量辉光；
- 执行动作采用高饱和极客绿 `#10B981`，警示采用暖琥珀 `#F59E0B`，致命危险采用鲜红 `#EF4444`。

### 2.3 数据类型专色 (Cell Type Tokens)
- `NULL`：`#64748B`（灰色斜体，清晰辨识空值）
- `NUMBER / INT / DECIMAL`：`#38BDF8`（天蓝色，便于快速扫视数值）
- `VARCHAR / TEXT`：`#F8FAFC`（高对比纯白，易于长文本阅读）
- `DATETIME / TIMESTAMP`：`#FB923C`（暖橙色，时间维度一目了然）
- `BOOLEAN / TINYINT`：`#C084FC`（浅紫色，状态分明）
- `JSON / BLOB`：`#34D399`（薄荷绿，提示可展开树状查看）

## 3. 核心交互流程重构

### 3.1 结果面板体验升维
- **子 Tab 切换无缝化**：在数据行数、表结构、外键关系、执行计划之间切换时，保持各自内部的滚动位置与选区，杜绝重载闪烁；
- **转置视图快捷操作**：按下 `Cmd+\` 即可在“标准宽表格”与“纵向键值卡片”之间瞬间切换，特别适合查看 `SELECT * FROM orders WHERE id = ?` 这种只有 1~2 行但有 40 列的详情；
- **单元格原地内联编辑**：双击单元格变为深色微发光 Input，修改后单元格右上角打上细小的琥珀色脏标记（Dirty Tag），顶部工具栏浮现 `保存修改 (2处)` 与 `放弃修改`。

### 3.2 AI 智能协同工作流
1. **输入阶段**：支持直接在输入框提问，或通过预设胶囊（`优化慢查询`、`添加复合索引`、`聚合统计`）一键填充；
2. **推理阶段**：`ThinkingBlock` 折叠展示模型思考链；`ExecutionBlock` 采用三态脉冲节点展示后台 MCP 工具调用与 Schema 获取；
3. **输出阶段**：生成的 SQL 放入高亮卡片，提供快捷按钮：
   - `▶ 立即执行 (Cmd+Enter)`：原地运行并将结果自动加载到左侧结果表格；
   - `⎘ 填入编辑器`：将 SQL 写入当前编辑器 Tab 的光标位置；
   - `在新 Tab 打开`：新建一个独立 SQL Tab 打开该语句，不破坏当前查询；
   - `复制`：直接进剪贴板。
4. **安全审查**：对破坏性 DDL/DML 自动高亮红色警戒框，并阻断执行直到用户在确认模态框中核准。

### 3.3 现代双卡片分层与实体分割条规范 (Dual Inset Cards Architecture)

针对上下相邻工作区（SQL 编辑器区 vs 查询结果面板区）容易出现的“按钮粘连、感觉不出分层”的视觉痛点，制定并落地了业界顶级现代开发工具（Linear / Cursor / DBX）的**双卡片内嵌式空间架构**：

1. **主画布内嵌卡片布局 (Floating Card Inset Layout)**：
   - 核心工作区不再采用生硬的平铺满屏切割，而是在画布内设置 `padding: 10px 12px`；
   - **SQL 编辑器区** 自身作为一块**独立的悬浮卡片容器**：拥有独立的圆角（`border-radius: 10px`）、精细边框（`border: 1px solid #232A3D`）与微投影（`box-shadow: 0 4px 18px rgba(0,0,0,0.4)`）；
   - **结果数据区** 同样作为一块**完全独立的下层卡片容器**，两块卡片像镶嵌在控制台上的精密仪器模块，从根本上杜绝了平铺混作一团的感觉。
2. **编辑器专属底栏 (Editor Footer Bar) 托住代码**：
   - 编辑器代码区底部新增高 `26px` 的独立底栏状态槽（展示当前语言 `MySQL 8.0`、光标行列号 `Ln 7, Col 12`、字符编码与快捷键提示）；
   - 这在物理上为 SQL 代码赋予了坚实的基底，彻底告别了“代码最后一行紧贴着下方工具栏”的局促下坠感。
3. **操作归属明确化与防换行防御 (Clear Action Ownership & No-Wrap)**：
   - 编辑器相关的执行动作（`▶ 运行选区 (⌘↵)`、`运行全部`、`EXPLAIN`、`格式化`、`片段`、`AI 改写`）统一收拢在**编辑器顶栏右侧**（与 SQL Tab 栏并列），严禁悬浮在编辑器底边；
   - 结果面板的操作（`数据/表结构/表关系/执行计划`、`多结果集标签`、`转置视图`、`导出 CSV`）归属于**结果栏顶部**。所有工具栏强制声明 `white-space: nowrap; flex-wrap: nowrap;`，杜绝多结果标签在窄屏下被挤到第二行的换行 Bug。
4. **工业级物理拖拽分割区 (Draggable Pane Resizer)**：
   - 在两张卡片之间的间隙中，设置 `12px` 高度的专用拖拽过渡带，中心悬浮 `44px × 4px` 的圆润防滑手柄（`resizer-handle`）；
   - 悬停时手柄平滑展开至 `60px` 并亮起蓝紫色品牌微光，赋予界面原生桌面工具的机械秩序与灵敏反馈。
