Workflow Fit

FAQ

常见问题

说明当前数据源、模型接入、安全护栏与使用边界。

当前核心数据源为 MySQL 与 Redis。页面不承诺未经验证的兼容数据库版本或全部 Redis 管理能力。
支持 OpenAI 兼容接口、Ollama 与自定义模型端点；同时提供 Anthropic 协议支持。具体模型可用性取决于端点配置与服务商实现。
使用云模型时，为完成请求，端点可能收到用户问题、SQL、Schema、查询结果、知识库片段、文本附件等必要上下文。AI 查询结果默认按规则脱敏；第三方如何处理或留存数据，由对应服务商策略决定。使用本地 Ollama 或自托管端点可进一步控制数据路径。
手动执行不带 WHERE 或 LIMIT 的 UPDATE / DELETE 时需要确认；AI 发起的写操作同样需要确认，破坏性 DDL 默认拒绝。审计记录用于帮助回看操作，但不能替代数据库自身的权限、备份和审批制度。
可将当前已经加载到工作台的查询结果导出为 CSV、XLSX 或 JSON。它不是整库导出、迁移或备份能力。
三种入口共享 Rust 核心，但面向不同工作流：GUI 适合可视化操作，TUI 适合终端与 SSH，MCP Server 用于让支持 MCP 的 AI 客户端调用受控数据库工具。
