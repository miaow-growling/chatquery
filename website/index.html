FAQ

常见问题

数据、模型与安全边界的简要说明。

数据源支持 MySQL 与 Redis；模型可接 OpenAI 兼容接口、Ollama、自定义端点及 Anthropic 协议。具体可用性取决于端点配置。
端点可能收到问题、SQL、Schema、查询结果及所引用的文本上下文。默认规则会脱敏查询结果，本地或自托管端点可进一步控制数据路径。
高风险 UPDATE / DELETE 与 AI 写操作需要确认，破坏性 DDL 默认拒绝。审计记录不能替代数据库权限、备份和审批。
可导出当前已加载的查询结果，格式包括 CSV、XLSX 与 JSON。整库迁移和备份不在此范围内。
三种入口共享核心能力：GUI 用于可视化操作，TUI 面向终端与 SSH，MCP 供 AI 客户端调用受控工具。
